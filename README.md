# 🖼️ Exhibitopia

**Exhibitopia** is a museum discovery and ticketing web application designed to help users explore nearby museums and exhibitions. With an interactive chatbot interface, users can view museum details, categories, upcoming shows, and securely book tickets — all in one place.

## 🚀 Features

- 🔎 Search and discover museums located in Kolkata
- 💬 Interactive chatbot for museum recommendations
- 🎟️ Online ticket booking with payment integration
- 🗂️ Categorized exhibitions and shows
- 📱 Responsive and user-friendly design

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Chatbot**: Integrated for navigation and ticketing assistance
- **Payment Gateway**: Connected to enable online ticket purchases
- **Deployment**: Netlify

## 📌 How It Works

1. Browse through available museums in Kolkata.
2. Use the chatbot to get personalized suggestions.
3. View details of shows and exhibitions.
4. Register and book your tickets online.

## 💡 Future Enhancements

- User login and profile management
- Review and rating system for museums
- Admin dashboard for museum managers
